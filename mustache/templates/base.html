About MustaCHE v2

MustaCHE (Multiple Cluster Hierarchies Explorer) is a tool for analyzing hierarchical density-based clustering results.

Version Information

Package version: {{ mustache_version }}

Main engine: CORE-SG. Auxiliary comparison baseline: HDBSCAN.

Technology stack: Flask, Python, CORE-SG, HDBSCAN, scikit-learn and Plotly.js
