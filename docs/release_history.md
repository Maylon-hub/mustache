# Release history

The current stable pair is
[`mustache-core==0.3.0`](https://test.pypi.org/project/mustache-core/0.3.0/)
and
[`core-sg-mustache==0.4.5`](https://test.pypi.org/project/core-sg-mustache/0.4.5/)
on **TestPyPI**. Official PyPI publication, MIDAS integration and article
submission are deferred. The source is integrated into the personal canonical
repositories: [MustaCHE `master`](https://github.com/Maylon-hub/mustache/tree/master)
and [CORE-SG `main`](https://github.com/Maylon-hub/core-sg/tree/main).

The historical `0.3.0rc3` / `0.4.5rc3` pair was qualified and published on
TestPyPI before the stable pair. Its archived
[RC preparation procedure](rc_preparation.md) records that milestone; it is
not the current installation guide. See the
[stable release notes](https://github.com/Maylon-hub/mustache/blob/master/RELEASE_NOTES.md)
and [changelog](https://github.com/Maylon-hub/mustache/blob/master/CHANGELOG.md).
